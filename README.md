# Сложно сосредоточиться

**[Открыть работающий сайт](https://arsen4ik6265.github.io/slozhno-sosredotochitsya-fd/)**

Адаптивный веб-сайт, который я самостоятельно разработал по техническому заданию во время обучения в Яндекс Практикуме.

## О проекте

«Сложно сосредоточиться» — информационный сайт о причинах снижения концентрации внимания и способах справляться с отвлекающими факторами.

Главная особенность проекта — адаптивный интерфейс с переключением цветовых тем.

## Что реализовано

- Адаптивная вёрстка для мобильных устройств, планшетов и компьютеров.
- Три режима оформления: «День», «Авто» и «Неон».
- Переключение тем с помощью JavaScript.
- Автоматический выбор оформления с учётом настроек устройства.
- Сохранение выбранной темы в localStorage.
- Работа с CSS-переменными и медиазапросами.
- Структурированная HTML-разметка.
- Интерактивные элементы интерфейса.

## Технологии

- HTML5.
- CSS3.
- JavaScript.
- Flexbox и Grid.
- CSS-переменные.
- Медиазапросы.
- DOM и обработка событий.
- localStorage.

## Структура проекта

- \`index.html\` — основная страница сайта.
- \`styles/\` — стили оформления и цветовых тем.
- \`scripts/script.js\` — логика переключения и сохранения тем.
- \`images/\` — изображения и графические элементы.
- \`fonts/\` — локальные шрифты.
